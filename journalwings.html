JournalWings

Finance Workflow Automation

A Python-based internal tool designed to automate and standardise a previously manual finance journal preparation process.

The problem

Preparing finance journals involved repetitive manipulation of transaction data, multiple manual checks and a number of decisions that had to be repeated each time the process was carried out.

On larger journals this could take several hours and created opportunities for inconsistent processing and manual error.

The solution

I designed and built JournalWings as a reusable Python application that takes source financial data and converts it into structured journal outputs using defined business rules.

The application applies automated transformations, validation and consistency checks before producing the final output, reducing the amount of transaction data users need to manipulate directly.

How it works

The user loads the required source files, selects the appropriate journal workflow and runs the process through a guided interface.

JournalWings then processes the source data, applies the relevant rules and validation checks, and generates the required structured output for the next stage of the finance workflow.

Impact

JournalWings reduces repetitive manual handling, improves consistency and traceability, and saves several hours of processing time on larger journal workflows.

Rather than being built as a single-purpose script, the application was designed as a reusable workflow tool capable of supporting multiple journal scenarios.

Technology

Python Excel openpyxl Data Validation Business Rules Workflow Automation

Design approach

The focus was not simply on automating individual spreadsheet steps. I wanted to turn the overall process into a guided workflow that reduced the number of manual decisions required from the user.

Validation and business rules are applied within the application so that potential issues can be identified earlier in the process rather than after journal outputs have already been prepared.
