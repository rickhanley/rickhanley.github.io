FileFlow

Guided Document Workflow

A Python-based desktop tool that turns inconsistent document naming and filing into a guided, repeatable workflow for non-technical users.

The problem

Document naming and filing relied on users repeatedly deciding how files should be named and where they should be stored.

The underlying rules were consistent, but they were being applied manually. That made the process slower than it needed to be and created opportunities for inconsistent naming, misplaced files and avoidable rework.

What I built

I built FileFlow to turn those rules into a guided workflow.

Users drag files into the application and FileFlow uses folder context, configurable rules and validation logic to determine the appropriate naming and destination.

The aim was to remove repetitive decisions from the user while still keeping the workflow transparent and easy to control.

How it works

FileFlow reads the context of the files being processed and applies the relevant naming and filing rules automatically.

Instead of requiring users to remember conventions or manually reconstruct filenames, the application guides them through the process and applies consistent logic before files are moved or renamed.

Safeguards and validation checks are built into the workflow to reduce the risk of incorrect naming or file placement.

Demo

Impact

FileFlow turns a loosely defined manual task into a consistent, repeatable process that is easier for non-technical users to follow.

It reduces the number of decisions users need to make, improves consistency across document handling and helps prevent common naming and filing errors.

Why I built it

The process worked, but too much of it depended on people remembering conventions and making the same small decisions again and again.

FileFlow was an experiment in moving those decisions into the tool itself, so the user could concentrate on the task rather than the mechanics of naming and organising files.
